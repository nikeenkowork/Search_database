Выполнение курсового проекта "Поиск информации с подключением БД"

В рамках курсового проекта был реализован класс DBManager, предназначенный для работы
с базой данных PostgreSQL.

Класс обеспечивает подключение к базе данных и выполнение основных SQL-запросов,
включая получение информации о странах и самолётах, расчёт агрегированных значений
(например, средней скорости), а также фильтрацию данных по различным критериям.

Реализация класса позволяет централизовать работу с базой данных и упрощает
взаимодействие с SQL-слоем приложения.


# Основные возможности класса DBManager:
  - установление соединения с базой данных PostgreSQL;
  - получение списка стран и количества связанных с ними самолётов;
  - получение полного списка самолётов;
  - вычисление средней скорости самолётов;
  - выборка самолётов с скоростью выше средней;
  - поиск самолётов по ключевому слову (callsign);
  - корректное закрытие соединения с базой данных.
